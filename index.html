The cheapest bid was the most expensive.

Four subcontractors bid the same electrical package in four different formats: a PDF, an Excel workbook, pricing typed into an email body, and a proposal revised after an addendum. Plumbline reads all of them, maps every proposal onto one scope vocabulary, and prices what each bidder left out. The low bidder moved from first to last. It also found the arc-flash study required by specification 26 05 73 that none of the four bidders covered, which no side-by-side price comparison can surface.

How it works

The pipeline

The division of labor is deliberate. The model reads prose and decides what a sentence means. Every number, ranking, and finding is computed in ordinary code, which is what makes the output reproducible and auditable rather than a fresh opinion on each run.

01

Intake

Bid arrives with attachments. File is SHA-256 hashed before anything else touches it.

Deterministic
02

Extract

Page-aware text from PDF or sheet-aware text from Excel, plus the email body when pricing lives there.

Deterministic
03

Interpret

Claude maps prose onto the fixed scope taxonomy and pulls figures, returning schema-constrained output with citations.

AI
04

Level

Scope gaps priced using estimator-entered values. Rankings, sums, and anomaly rules all computed in code.

Deterministic
05

Decide

Findings and a leveled comparison go to the estimator. The system never awards a bid.

Human
Why the AI boundary sits there. Reading a paragraph and deciding whether a vendor included permit fees is genuinely hard and genuinely language work. Adding four numbers and sorting the result is not. Letting a model do the arithmetic would trade a reproducible answer for an unreproducible one and buy nothing.

Step 05 · Findings

What the estimator needs to act on

Eleven findings from seven deterministic rules, sorted by severity. Every one is arithmetic or a set comparison, so each can be explained and reproduced exactly.

Required scope missing from every bidder

The arc-flash study required by specification section 26 05 73 is not included by any of the four bidders. Because all four omitted it, nothing in a price comparison looks unusual, yet the entire package is underpriced against the specification. This is the finding a side-by-side price sheet structurally cannot produce.

Ironclad Power & Electric: Original superseded by Revision 1 (−$4,550 after Addendum 2 deleted the standby generator feeder). Comparison uses the latest revision.

One rule ran and stayed silent. The low-outlier check looks for any bid more than 10% below the median. Voltage is 6.7% below, so it does not fire. That silence is reported as a result rather than hidden, and it is asserted in the test suite. A system that manufactures a finding for every bid teaches estimators to ignore findings.
Under the hood

How correctness is proven

Because every fixture in this demo was authored deliberately, the right answer is known before the pipeline runs. That makes the output checkable rather than merely plausible.

75 deterministic tests

The full suite runs with recorded model responses, so continuous integration never depends on a live API call, a network connection, or a model's mood on a given day.

55 golden assertions

A hand-authored answer key covers rankings, adjusted totals, the scope matrix, revision diffs, and every expected finding, including the one expected to stay silent.

Schema-constrained output

The extraction schema is passed to Claude as a tool definition, so responses are shape-valid before they reach any business logic, then validated again before persistence.

Full inference lineage

Every AI output is stored separately from vendor-submitted fact, with provider, model, prompt version, source document hash, confidence tier, and review status.
